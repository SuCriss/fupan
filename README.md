# A股涨停复盘

一套 A 股涨停复盘工具：全市场扫描、涨停/连板/炸板/跌停分类、连板天梯、龙头打分、板块聚类、昨日对比、个股分时与 K 线。

前端 React + 后端 FastAPI，数据来自公开行情接口，全部本地运行。

## 逆向来源

本工具的功能与 `http://101.43.83.23/fupan/`（"龙买复盘 Web 3.4"）对标。原站是纯前端静态页 + 私有后端，本实现重建了它的页面结构与分析口径，但后端逻辑与数据源为独立实现。

## 快速开始

### 1. 后端

```powershell
cd fupan\server
.\.venv\Scripts\python.exe -m uvicorn fupan.app:app --host 127.0.0.1 --port 8000
```

依赖安装（首次）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 2. 前端

另开一个终端：

```powershell
cd fupan\web
npm install
npm run dev      # 开发模式，访问 http://localhost:5173
```

或构建后由后端直接托管（单进程部署）：

```powershell
cd fupan\web
npm run build
# 之后直接访问 http://127.0.0.1:8000
```

## 功能

| 标签页 | 内容 |
|---|---|
| 龙头榜 | 按综合评分排序的涨停梯队卡片，带概念标签 |
| 涨停池 | 全部涨停股，可按任意列排序、搜索 |
| 连板池 | 2 板及以上个股 |
| 炸板池 | 盘中触及涨停但未封住的个股 |
| 跌停池 | 跌停个股 |
| 连板天梯 | 自高向低的连板层级，标注断层与晋级数 |
| 热股榜 | 按成交额加权的热度排名，带概念标签 |
| 昨日对比 | 昨日与今日梯队并排，附连板晋级率 |
| 回撤榜 | 从盘中最高点回落幅度最大的个股 |

顶部「概念聚合」栏按真实概念题材（如"央国企改革 9 家""电池技术 8 家"）聚合当日涨停。聚合计数与点击筛选后的列表行数**始终一致**（两边都基于个股的完整概念列表）。

### 个股详情

点击任意股票打开详情抽屉：

- **三图同轴 K 线**：蜡烛图 + MA5/10/20/60 均线、成交量、MACD（DIF/DEA/柱）三窗格共用一条时间轴
- **缩放与平移**：滚轮以光标为锚点缩放、拖动平移、＋/－/重置按钮，自动按可视区间重算 Y 轴
- **周期切换**：日线 / 周线 / 月线 / 季线 / 分时，切换后图表与结论同步重绘
- **十字光标**：悬停显示该根的 开/高/收/低/量/振幅 与 MA、DIF、DEA 共 12 项
- **量价分析结论**：多空评分、区间位置条、特征标签（均线多头、MACD金叉、放量…）
- **AI 归因摘要**：大模型生成的三行归因（核心逻辑 / 驱动因素 / 风险提示）
- **评分拆解**：七项分项的得分条与说明
- **关键数据**：封单额、封单比、换手、市值、开板次数、板块家数等十二项
- **概念题材**：真实概念板块标签，以及每条概念的入选依据

详情接口平均 **< 1 秒**（首次含上游请求），命中 45 秒内存缓存后约 **40 毫秒**。四项上游请求（行情/分时/K线/概念）并发执行，且不再触发全市场快照重建。

## AI 归因摘要

原站的"涨停原因"长文由其私有后端生成，公开接口没有。本实现用大模型基于**本站已采集的事实**生成，避免凭空编造。

输入模型的事实：今日行情、连板高度与板型、封单与换手、流通市值、概念题材、每条概念的公告依据、所属行业。

**配置**：编辑 `server/.env`（已加入 `.gitignore`），参考 `server/.env.example`：

```ini
FUPAN_LLM_BASE_URL=https://api.deepseek.com/v1
FUPAN_LLM_API_KEY=sk-xxxx
FUPAN_LLM_MODEL=deepseek-chat
FUPAN_LLM_TIMEOUT=60
```

兼容任何 OpenAI 协议的接口（DeepSeek / 通义 / Kimi / 智谱 / OpenAI 等）。留空则功能关闭，界面显示"暂不可用"。

**防幻觉与合规**：

- 提示词约束只引用给定事实，依据不足须写"暂无公开依据"
- 输出规范化为三行结构；模型若输出散文或表格，会被重排或剔除
- 生成后经清洗层，剔除任何操作建议（追高/买入/卖出/目标价/止盈止损等）与残留 Markdown
- 摘要按 `(代码, 交易日)` 落库缓存，当日不重复生成

**生成时机**：异步。打开详情页立即渲染（不等模型），摘要生成完后前端每 2.5 秒轮询自动填入，通常 5–15 秒。

## 概念题材与行业分类

两套独立分类，都用到且不混用：

| 分类 | 示例 | 来源 | 用途 |
|---|---|---|---|
| **概念题材** | 水产概念、预制菜概念、央国企改革 | 东财 datacenter（`IS_PRECISE=1`） | 概念标签、概念聚合、热股榜、板块评分 |
| **行业** | 农林牧渔、农产品加工 | 东财 F10 `ssbk` | 行业归属展示 |

## 评分模型

七项加权，合计 100 分：

| 分项 | 权重 | 口径 |
|---|---|---|
| 高度 | 35 | 连板数为主，`N天M板` 给部分分 |
| 封单 | 18 | 封单额对数缩放 |
| 板型 | 14 | 一字板 > T字板 > 换手板，开板次数扣分 |
| 换手 | 8 | 5%–15% 为最优区间 |
| 成功率 | 8 | 历史封板成功率（数据源不提供时置 0） |
| 板块 | 17 | 同一概念题材的涨停家数 |
| 身位 | 4 | 是否市场最高板 |

总分 ≥80 龙头 · 主攻；≥60 强势 · 接力；≥40 跟风 · 观察；其余 薄弱 · 回避。

## 数据源与已知限制

| 用途 | 来源 | 说明 |
|---|---|---|
| 全市场行情 | 新浪 Market_Center | 约 4800–5200 只，含涨跌幅、换手、市值 |
| 个股分时 | 腾讯 minute | 可用 |
| 日 K 线 | 腾讯 fqkline（前复权） | 详情页取 600 根，支撑周/月/季线 |
| 概念题材 | 东财 datacenter `RPT_F10_CORETHEME_BOARDTYPE` | `IS_PRECISE=1` 为真实概念，含入选依据 |
| 行业归属 | 东财 F10 `ssbk` | 展示用 |

**限制（均已在代码中标注）：**

- **东方财富 `push2` 行情接口在部分网络下不可达**（TLS 被重置），因此全市场行情改用新浪接口；datacenter 与 F10 不受影响。
- **封单额是估算值**，由涨停时的成交额推算，非真实封单量（快照接口不提供）。
- **开板次数是估算值**，由当日振幅推断（无逐笔数据）。
- **封板成功率暂无数据源**，该分项当前恒为 0（原站据此扣分，本实现不扣）。
- **概念题材不是"涨停原因"原文**。原站的 `reason`（如"羊字辈+体外诊断+…"）与 `analyse`（长文分析）由其后端 AI 生成，公开接口无此数据。本实现用概念板块的**入选依据**（来自公司公告/年报）作为替代，口径可核查但不如原站聚焦当日炒作逻辑。
- **昨日对比依赖日 K 线重建**，不含昨日的封单额与板型。
- **首次冷启动约 2 分钟**（需扫描全市场 K 线），之后当日刷新约 40 秒，因为 K 线、概念与昨日天梯都已缓存。

## 缓存

所有缓存写入 `data/fupan.db`（SQLite）：

| 表 | 内容 |
|---|---|
| `snapshots` | 每日完整快照 |
| `boards` | 每日连板记录 |
| `klines` / `kline_meta` | 日 K 线缓存 |
| `stock_sectors` | 行业归属缓存（90 天） |
| `stock_concepts` | 概念题材缓存（30 天） |
| `prev_ladder` | 昨日天梯缓存（每交易日一次全扫描） |
| `watchlist` | 自选股 |

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/all?date=` | 完整复盘文档（stats/leaders/ladder/hot/pools/compare） |
| POST | `/api/refresh` | 强制重新抓取 |
| GET | `/api/market` | 指数行情与交易状态 |
| GET | `/api/stock/{code}` | 个股详情（行情/分时/K线） |
| GET | `/api/watch?codes=` | 自选股或指定代码行情 |
| POST/DELETE | `/api/watch/{code}` | 增删自选股 |
| GET | `/api/dates` | 已缓存快照日期 |
| GET | `/api/health` | 健康检查 |

交互式文档：`http://127.0.0.1:8000/docs`
